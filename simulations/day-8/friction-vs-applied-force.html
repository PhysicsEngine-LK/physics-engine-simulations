222සීමාකාරී සහ ගතික සර්ෂණ බල
තිරස් පෘෂ්ඨයක් නිසා අභිලම්බ ප්‍රතික්‍රියාව බරට සමානයි: R = mg = 100 × 10 = 1000 N f_limiting = μR = 0.2 × 1000 = 200 N f_kinetic = μₖR = 0.18 × 1000 = 180 N μₖ < μ නිසා චලනය වන විට සර්ෂණය, චලනය ආරම්භ වීමට පෙර උපරිම සර්ෂණයට වඩා අඩුයි.
223P අනුව f වෙනස් වන හැටි
• P ≤ 200 N: කුට්ටිය නිශ්චලයි. ස්ථිතික සර්ෂණය "අවශ්‍ය තරමට" පමණක් ක්‍රියා කරයි, එනිසා f = P (0, 100, 150 N).
• P = 200 N: f එහි උපරිම අගය වන 200 N ට ළඟා වේ – සීමාකාරී සමතුලිතතාව (චලනය වීමට ආසන්නයි).
• P > 200 N: ස්ථිතික සර්ෂණයට P සමතුලිත කළ නොහැක, කුට්ටිය චලනය වේ. දැන් f = f_kinetic = 180 N (205 N, 250 N දෙකටම), P මත රඳා නොපවතී.
224P = 250 N විට ත්වරණය
කුට්ටිය චලනය වන නිසා f = 180 N. නිව්ටන්ගේ දෙවන නියමය (F = ma): P − f = ma → 250 − 180 = 100 × a a = 70 / 100 = 0.7 ms⁻²
225f – P ප්‍රස්තාරය
ඉහත ප්‍රස්තාරය බලන්න:
• 0 ≤ P ≤ 200 N : f = P (මූල ලක්ෂ්‍යය හරහා අනුක්‍රමණය 1 වූ සරල රේඛාව).
• P = 200 N දී f උපරිමයි (f_limiting = 200 N).
• P > 200 N : f හදිසියේ 180 N ට අඩු වී, ඉන්පසු තිරස් රේඛාවක් ලෙස නියතව පවතී (f_kinetic = 180 N).
