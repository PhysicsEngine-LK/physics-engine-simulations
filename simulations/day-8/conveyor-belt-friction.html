249සම්පූර්ණ පැහැදිලි කිරීම
0 < t < t₀ : පෙට්ටියේ වේගය පටියේ වේගයට වඩා අඩුයි. එනිසා පටියට සාපේක්ෂව පෙට්ටිය පිටුපසට ලිස්සයි. මෙම සාපේක්ෂ චලිතයට විරුද්ධව පෙට්ටිය මත ඉදිරියට ගතික සර්ෂණයක් ක්‍රියා කරයි: F = μₖR = μₖmg (නියතයි) → a = μₖg t = t₀ : පෙට්ටියේ වේගය = පටියේ වේගය (u). සාපේක්ෂ චලිතය නවතී. u = 0 + μₖg·t₀ → t₀ = u / μₖg t > t₀ : පටිය නියත ප්‍රවේගයෙන් යන නිසා පෙට්ටියද නියත ප්‍රවේගයෙන් යයි → a = 0 → සම්ප්‍රයුක්ත බලය ශුන්‍යයි. පෙට්ටිය මත ඇති එකම තිරස් බලය සර්ෂණය නිසා F = 0. (ලිස්සීමේ ප්‍රවණතාවක්වත් නැති නිසා ස්ථිතික සර්ෂණයක්ද අවශ්‍ය නැත.)
