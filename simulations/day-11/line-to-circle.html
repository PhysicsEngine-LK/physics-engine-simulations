සරල රේඛාවකින් වෘත්තයකට 🎾

අභ්‍යවකාශයේ ටෙනිස් බෝලයක් නියත ප්‍රවේගයෙන් සරල රේඛාවක යයි (නිව්ටන් I). එහි චලිතයට හරියටම 90° ක් ලෙස හදිසි තල්ලුවක් දුන්නොත් දිශාව වෙනස් වේ, වේගය නොවේ. සමාන කාල පරතරවලින් නැවත නැවත තල්ලු කළොත් → බහුඅස්‍රයක්. පරතරය කෙටි කරන්න කරන්න → වෘත්තයක්! N ස්ලයිඩරය 4 සිට ∞ දක්වා ගෙන යන්න.

තල්ලුව සෑම විටම v ට ලම්බයි; එක තල්ලුවකින් v හැරෙන්නේ 360°/N කින් (N = ∞ විට අතින් තල්ලුවකට 10°). v = 4 m s⁻¹, r = 4 m.

a⚡ වේගය වෙනස් නොවන්නේ ඇයි?
තල්ලුව (බලය) සෑම විටම බෝලයේ චලිත දිශාවට ලම්බයි. ලම්බ බලයකින් චලිත දිශාවට කාර්යයක් සිදු නොවේ: W = F s cos 90° = 0 කාර්යය ශුන්‍ය නම් චාලක ශක්තිය (½mv²) වෙනස් නොවේ → වේගය |v| නියතයි. වෙනස් වන්නේ දිශාව පමණයි 😊
නමුත් ප්‍රවේගය දෛශිකයක්. දිශාව පමණක් වෙනස් වුණත් ප්‍රවේගය වෙනස් වෙලා → ත්වරණය ≠ 0.
b🔷 බහුඅස්‍රය වෘත්තයක් වන්නේ කොහොමද?
එක වටයක් යන්න බෝලය මුළු 360° ක් හැරිය යුතුයි. N වතාවක් සමානව තල්ලු කළොත් එක තල්ලුවකින් හැරෙන කෝණය: Δθ = 360° / N • N = 4 → 90° → සමචතුරස්‍රය (සටහනේ "90° තල්ලුව" මෙයයි)
• N = 8 → 45° → අෂ්ටාස්‍රය
• N = 32 → 11.25° → දැනටමත් වෘත්තයක් වගේ!
N වැඩි වන විට තල්ලු අතර කාලය කෙටි වේ, එක් හැරීමක් කුඩා වේ, කොන් නැති වී යයි. N → ∞ (අඛණ්ඩ බලය) විට මාර්ගය වෘත්තයක්. පෙර N වල හැඩ මැකී නොයන නිසා ඒවා වෘත්තයට ළං වන හැටි බලන්න. සාමාන්‍ය a = Δv / Δt = (v²/r)·cos(180°/N) → v²/r

සියුම් කරුණක්: N කුඩා විට (උදා. N = 4) එක තල්ලුව ලොකුයි; එය හරියටම යොමු වන්නේ කේන්ද්‍රය දෙසටයි (පෙර සහ පසු ප්‍රවේගවල මැදට ලම්බව). තල්ලු කුඩා වන විට එය v ට හරියටම 90° ක් වේ.

🔥NOTE: වෘත්ත චලිතය යනු කුමක්ද?
වෘත්ත චලිතය කියන්නේ අමුතු දෙයක් නොවේ. එය නිව්ටන්ගේ පළමු නියමය (සරල රේඛාවේ යාම) නොකඩවා බාධා කිරීමක් පමණයි.
සෑම මොහොතකම ප්‍රවේගයට ලම්බව, සෑම විටම කේන්ද්‍රය දෙසට ක්‍රියා කරන බලයක් (ත්වරණයක්) තිබේ නම් → වෘත්ත චලිතය.
එම බලය = කේන්ද්‍රාභිසාරී බලය (centripetal force): a = v²/r F = mv²/r (කේන්ද්‍රය දෙසට) එය අලුත් වර්ගයේ බලයක් නොවේ. තන්තුවක ආතතිය, ගුරුත්වය, සර්ෂණය වැනි ඕනෑම බලයකට මේ "කේන්ද්‍රය දෙසට" රාජකාරිය කළ හැක.
d✋ බලය ඉවත් කළොත්?
බලය නැති වූ මොහොතේම ත්වරණය = 0. නිව්ටන්ගේ පළමු නියමය අනුව බෝලය එම මොහොතේ තිබූ ප්‍රවේගයෙන්ම, එනම් ස්පර්ශකය දිගේ, සරල රේඛාවක යයි. කේන්ද්‍රයෙන් ඉවතට (අරය දිගේ) පියාඹා යන්නේ නැත! "බලය ඉවත් කරන්න" ඔබා බලන්න.
